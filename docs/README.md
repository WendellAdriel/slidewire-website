## Introduction

SlideWire is a Laravel package for building presentation decks with Livewire. Presentations are authored as Blade files, rendered as a full-page Livewire experience, and support navigation, themes, fragments, code highlighting, diagrams, vertical stacks, and timed auto-slide flows.
